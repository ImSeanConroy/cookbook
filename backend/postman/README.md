# Postman Workspace

This folder contains Postman assets for local development and testing of the backend API.

## Files

- `Cookbook API.postman_collection.json`: Starter request collection for core routes.
- `Development.postman_environment.template.json`: Template environment with non-secret defaults.

## Setup

1. Open Postman.
2. Import both files from this folder.
3. In Postman, duplicate the template environment and rename it (for example, `Cookbook Local`).
4. Select that environment before sending requests.
